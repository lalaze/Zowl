# Retain immutable transaction revisions

Zowl keeps current state in `transactions` for queries and statistics, appending immutable revisions for initial posting and every successful amendment. Revisions capture canonical facts, actor, time, confirmation identity, and duplicate overrides. Failed attempts and incomplete reviews create no revisions; file and screenshot workflows retain their own review history. Current state plus history avoids permanently losing correction evidence without the complexity of full event sourcing. Every posted write must maintain current state and revisions atomically.
